# 舰船系统 允许的偏离

## 可以
- 改包名/类名：用 new.mjs，不要手改 package 行
- 改数值：先改 SPEC 数值要求，再改骨架常量
- 加方法：先在本表补一条 pitfalls，再改骨架
- 换接线方式：在 recipe.json 的 wiring 里改，不要只改生成出来的文件

## 不可以
- 删掉 // FILL: 注释（留着才知道哪里还没填）
- 绕过 sscore 自己再写一套滑块/列表/命中
- 在 advance/每帧里轮询鼠标键盘来判断点击
- 把持久化写进按钮回调或渲染函数

偏离超过两条时，先改 `_guide-data.json` 与骨架，再重新生成，而不是在产物里临时打补丁。
